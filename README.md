## 📦 Local Development

Want to run [www.catchbuild.com](https://www.catchbuild.com/) locally?

### Prerequisites
- [Hugo Extended](https://gohugo.io/installation/) 0.120.0+
- [Node.js](https://nodejs.org/) 18.0+

### Quick Start

```bash
# Clone the repository
git clone https://github.com/yourusername/catchbuild.git
cd catchbuild

# Install dependencies
npm install

# Start development server
hugo server -D

# Visit http://localhost:1313
```

### Build for Production

```bash
hugo --minify
```

Output will be in `public/` directory - ready to deploy to [www.catchbuild.com](https://www.catchbuild.com/).
